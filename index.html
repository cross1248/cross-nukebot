// safety

What Cross does and doesn't do.

TOKEN

Your user token is stored locally, encrypted at rest. It is never transmitted anywhere but Discord's own API.

SCOPE

Cross only touches servers where your user account already has Administrator permissions.

NETWORK

The only outbound connection Cross makes is to discord.com/api. No telemetry, no analytics pings.

SOURCE

Built and maintained as a personal tool. Source available on request for anyone who wants to audit it.
